# Firebase Storage Rules Setup Guide
# T.B. Lulla Foundation - Complete Implementation

## 🔥 How to Apply Storage Rules

### Step 1: Access Firebase Console
1. Go to https://console.firebase.google.com
2. Select your project: `admin-a6f7e`
3. Navigate to "Storage" in the left sidebar
4. Click on "Rules" tab

### Step 2: Update Rules
1. Copy the entire content from `FIREBASE_STORAGE_RULES.txt`
2. Paste it into the Firebase Console Rules editor
3. Click "Publish" to apply the rules

### Step 3: Verify Rules Are Active
1. Check the "Rules" tab shows your new rules
2. Test upload from admin panel
3. Verify public access from client side

## 🚨 Common Issues & Solutions

### Issue 1: "Permission Denied" on Upload
**Solution:** Ensure user is authenticated and has admin privileges

### Issue 2: "File Too Large" Error
**Solution:** Check file size limits in the rules above

### Issue 3: "Invalid File Type" Error
**Solution:** Ensure file type matches allowed content types

### Issue 4: Public Images Not Loading
**Solution:** Verify read rules are set to `allow read: if true`
